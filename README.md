 DeFi Classics

Эталонная реализация фундаментальных смарт-контрактов для DeFi. 

## О проекте
Данный репозиторий содержит безопасные, оптимизированные и готовые к аудиту смарт-контракты. Основное внимание уделяется минимизации вектора атак и соответствию стандартам безопасности OpenZeppelin.

## Реализованные контракты
* StableVault.sol: Хранилище активов стандарта ERC-20 с поддержкой:
  - Защиты от Reentrancy атак.
  - Управления доступом (Ownable).
  - Функции экстренной заморозки (Pausable).
  - Экстренного вывода средств (Emergency Withdraw).

## Безопасность
Все контракты написаны с использованием SafeERC20 и прошли базовую проверку на наличие критических уязвимостей. 

*Этот проект создан как эталонная реализация (Reference Implementation) для образовательных целей и участия в аудитах.*
